# 🚗 Obstacle Detection System - Stage 2

Hệ thống phát hiện chướng ngại vật nâng cao cho Intelligent Transport Systems.

## ✨ Tính năng mới (Stage 2)

### 🎥 **Thu nhận hình ảnh nâng cao**
- **Đa nguồn camera**: Hỗ trợ webcam, USB camera, IP camera (RTSP/HTTP)
- **Tự động kết nối lại**: Auto-reconnect khi mất kết nối
- **Picture-in-Picture (PIP)**: Hiển thị nhiều camera cùng lúc
- **Tự động điều chỉnh**: Exposure, white balance, focus

### 🖥️ **Hiển thị thông minh**
- **HUD đa cấp độ**: Vùng an toàn/cảnh báo/nguy hiểm
- **Radar hiển thị**: Hiển thị góc và khoảng cách chướng ngại vật
- **Heatmap**: Phân tích khu vực nguy hiểm thường xuyên
- **Telemetry**: Thông số phương tiện real-time
- **Chế độ hiển thị**: Normal/Min
